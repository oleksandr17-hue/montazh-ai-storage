Montazh AI storage

Montazh AI storage is a private tool used by a single video editor to back up and restore working files of their own video-editing projects (source clips, brand assets, finished videos) in their own Google Drive.

The tool uses only the drive.file permission: it can see and manage only the files it created itself (one folder named Montazh_AI_storage). It cannot see or change any other files in the user's Google Drive.

The tool is not offered to the public and has no other users.
