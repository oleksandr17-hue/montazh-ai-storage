Privacy Policy

App: Montazh AI storage · Last updated: 26 October 2026

What the app does

Montazh AI storage is a private backup tool used by one person (the app owner) to store and restore files of their own video-editing projects in their own Google Drive.

What data the app accesses

The app requests only the Google Drive scope https://www.googleapis.com/auth/drive.file. With it, the app can access only files and folders it created itself (the folder Montazh_AI_storage and its contents). It cannot read, list or change any other files in the user's Google Drive, and it does not access email, contacts, calendar or any other Google data.

How the data is used

  • Files are uploaded to and downloaded from the owner's own Google Drive only, to back up and restore video-editing projects.
  • The app stores the file name, size and a checksum of each file to check that a restore is complete.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.

Storage and security

Access credentials are kept only in the private settings of the owner's computing environment; they are never published, logged or stored in source code.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Files already stored remain in the owner's Google Drive and can be deleted there.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
